# Sharepoint_Labo

Documentation d'un lab de mise en place d'une infrastructure SharePoint Server SE (Hyper-V + AD DS + SQL Server + SharePoint), rédigée au fil de l'exercice.

## Structure

- **[Partie 1 - AD & SQL Server](./Partie%201%20-%20AD%20%26%20SQL%20Server/Tutoriel_SharePoint_Lab_Partie1.md)**
  Création des VMs Hyper-V, promotion du contrôleur de domaine, GMSA, installation de SQL Server 2022.

- **[Partie 2 - SharePoint SE](./Partie%202%20-%20SharePoint%20SE/Tutoriel_SharePoint_Lab_Partie2.md)**
  Prérequis SharePoint SE, installation de SharePoint Server SE, création de la ferme.

- **[Partie 3 - SharePoint SE - Structure du site](./Partie%203%20-%20SharePoint%20SE%20-%20Structure%20du%20site/Tutoriel_SharePoint_Lab_Partie3.md)**
  Utilisateurs/groupes AD, arborescence des sites SharePoint, applications, permissions.
